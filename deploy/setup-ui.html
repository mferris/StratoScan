WiFi ✓

Changing WiFi may briefly disconnect you. If this page stops responding, rejoin your home network and open this address again — the radar puts its old network back automatically if the new one doesn't work.

Receiver location ✓

Where the antenna physically is. Used to centre the radar. Kept on the device; if you later publish a public page, the position it shows is rounded to about half a mile.

In the US, longitude is west, so it is negative. If you leave the minus off, it is added for you.

Home airport ✓

Sets the landing/takeoff highlight and the approach heatmap.

Feed names can't be worked out from the airport code, so this is left blank unless you fill it in. Find yours at liveatc.net and paste the mount value. Blank simply turns the ATC feature off.

Public web address ✓

Optional. Uses your own Tailscale account, so the device and its location stay under your control. Create a free account, generate an auth key, and paste it here. Skip this to keep the radar on your home network only.
