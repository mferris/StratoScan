Getting started…

Sign in

This device has not been set up yet. Enter the code shown on the radar's own screen, then choose a password for it.

WiFi ✓

Changing WiFi may briefly disconnect you. If this page stops responding, rejoin your home network and open this address again — the radar puts its old network back automatically if the new one doesn't work.

Receiver location ✓

Where the antenna physically is. Used to centre the radar. Kept on the device; if you later publish a public page, the position it shows is rounded to about half a mile.

Looked up via OpenStreetMap. The address is sent to their geocoder and nowhere else; the position it returns stays on the device. Prefer not to? Enter coordinates instead.
Type the number without a sign and pick the hemisphere. Pasting a signed value works too. Look up an address instead.

Home airport ✓

Sets the landing/takeoff highlight and the approach heatmap.

Feed names can't be worked out from the airport code, so this is left blank unless you fill it in. Find yours at liveatc.net and paste the mount value. Blank simply turns the ATC feature off.

Time zone and region ✓

Sets the clock the radar timestamps everything with, and the WiFi regulatory region the radio is allowed to use. Both were fixed to the United States before; a unit used anywhere else showed the wrong time on every sighting.

The time zone applies immediately. The WiFi region is a radio setting and only takes effect after the device restarts.

Software update ✓

Updates are signed. The device will refuse anything that is not signed by the maintainer's key, and anything older than what it already has. If a new version fails to start, the old one is put back automatically — you do not have to be nearby.

Checking…

Public web address ✓

Optional. Uses your own Tailscale account, so the device and its location stay under your control. Create a free account, generate an auth key, and paste it here. Skip this to keep the radar on your home network only.

Change password

Changing it signs out every other device.

Reset

Reset settings clears the location and home airport but keeps this radar on your WiFi, so you can carry on using it.

Erase everything is for giving the radar to someone else. It removes your WiFi, your Tailscale account, your password, the receiver's location, and the flight history and approach heatmap built up at this address. The radar then starts its own setup network so the next person can claim it.
